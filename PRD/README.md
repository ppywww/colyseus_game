## 四、建议后续补充的文档

以下内容可在玩法细节进一步明确后再拆分：

- **武器与装备设计**：武器分类、伤害、射速、弹匣、装填、后坐力、投掷物参数及装备表现。
- **游戏规则与数值平衡**：胜负条件、回合 / 复活规则、各模式人数与限制、计分、伤害数值和整体平衡。
- **音效与音频资源规范**：音效分类、触发时机、混音、音量分组、资源格式与加载策略。
- **网络同步与测试验收**：网络质量目标、延迟 / 丢包测试、断线重连、并发压测和验收标准。

## 阅读与维护原则

1. 01 描述全局流程；02—05 描述页面；06—10 描述游戏内容、系统与视觉规范；11—12 描述客户端和服务端技术方案。
2. 页面文档记录页面功能和交互；系统文档记录跨页面或跨玩法的通用规则；技术选型文档记录当前实现、目标方案和待确认事项。
3. 未确认的内容标记为“待讨论”或“待确认”，不当作最终规则。
4. PRD 先于开发；文档更新不代表游戏代码已实现。
5. 技术方案应结合现有代码验证；例如光照和画面渲染通常属于客户端职责，服务端主要负责权威游戏状态、规则校验与同步。
6. 文档中的“已使用”表示已从代码确认；“建议 / 待确认”不代表已经接入。性能指标应以实测数据为准。
