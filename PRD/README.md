# 游戏 PRD（产品需求文档）

这里集中记录《Colyseus Game》后续的产品设计、体验目标、视觉规范、功能需求和迭代验收标准。

## 工作原则

1. **先讨论并形成文档，再修改代码。** 未经讨论确认的设计不直接当作开发要求。
2. 每项需求使用 Markdown 文档记录，保留讨论结论、待确认问题和变更记录。
3. 每次开发尽量对应已确认的 PRD 条目，完成后按文档中的验收标准检查。
4. 本目录只管理产品与设计决策；当前阶段不因建立 PRD 而修改游戏代码。

## 状态约定

- **待讨论**：已记录反馈，尚未形成方案。
- **待确认**：已有建议方案，等待用户确认。
- **已确认**：可作为后续设计与开发依据。
