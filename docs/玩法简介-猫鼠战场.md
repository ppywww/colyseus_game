# 猫鼠战场 · 玩法简介（v0.3）

> 配套 `产品视觉效果手册.html` 使用。这是玩法层的说明，视觉规范以手册为准。

## 一句话

四个卡通动物，在一间放大了三倍的厨房里，用枪和厨房道具打 **4v4 回合制对抗**。尺度反差是全部乐趣的来源。

## 定位

| 项 | 内容 |
| --- | --- |
| 类型 | 第一人称战术竞技（团队对抗） |
| 人数 | 4v4，单房间最多 8 人 |
| 时长 | 单回合 90 秒，先到 12 击杀或打满 5 回合 |
| 平台 | 浏览器（Three.js + Colyseus），桌面键鼠 |
| 底层 | 服务端权威：命中、伤害、投掷弹道全部由服务端裁定 |

## 核心循环

1. **出生推进**：鼠方从餐桌下的鼠洞出生，猫方从冰箱后出生，各自选一条通道。
2. **换血与抢点**：用地形与厨房物件当掩体换血，抢占奶酪点补充弹药。
3. **投掷物清点**：平底锅逼位、胡椒瓶破点、面粉袋切视线，抛物线所见即所得。
4. **回合结算**：MVP 与伤害榜，结算页承担表演欲。

## 角色

**四个角色只换外观，不换强度。** 血量、移速、武器、后坐力、受弹面积完全一致——
4v4 竞技里"选人即选强度"会让路人局第一秒就开始抢同一个角色，
所以四只只在毛色、耳朵、尾巴、体型轮廓与胸前配饰上做差别。

| 角色 | 物种 | 外观特征 | 体型系数 | 配饰 |
| --- | --- | --- | --- | --- |
| Tom | 灰蓝猫 | 尖立三角耳、长尾、无腮帮 | 0.96 | 围巾 |
| Jerry | 棕鼠 | 大圆盘耳、鼓腮、细尾 | 0.84 | 领结 |
| Spike | 斗牛犬 | 前折耷拉耳、宽下颌、短尾 | 1.00 | 项圈 + 铜牌 |
| Butch | 黑猫 | 尖耳、荧光绿眼、长尾 | 0.90 | 领结 |

> 体型系数只乘在**宽度**上（0.84–1.00），且上界必须是 1——判定体是按最宽体型算的，
> 任何人都不许比判定体宽。头部宽度系数 1.42–1.50，上限由 `0.085 × 1.5 < 0.13` 卡死。

**敌我识别靠配饰颜色**，不靠毛色：T 方围巾/领结是番茄红，CT 方是天空蓝。
这样"选 Jerry 的 T"和"选 Jerry 的 CT"能一眼分清，同时保住角色辨识度。

## 地图 · KITCHEN

**80m × 80m**（猫鼠视角下的厨房地面）。三条通道：

- **① 台面长台**：沿料理台前沿的高速走廊，能俯瞰中央地砖，但暴露在三条视线交叉处。
- **② 中央地砖**：最短路径，掩体最少，适合面粉袋掩护下快速转点。
- **③ 桌下通道**：头顶是桌腿与桌布，几乎不被高线打中；狭窄，易被一只平底锅封死。

15 个分区全部厨房化命名：两个包点是**灶台**与**水槽**，出生点是**鼠洞**与**猫窝**，
其余是台面长台 / 短台 / 猫道 / 冰箱前 / 中央地砖 / 水槽门 / 桌下通道 / 桌下低道 /
后厨走廊 / 灶台坡道。分区 id 保持不变（`site_a` / `site_b` / `spawn_t` …），只换中文名。

掩体全部是厨房物件：储物木箱、陶罐、餐车、切菜案台。箱顶还摆着奶酪楔、盘子、番茄、
牛奶瓶——既是"这块能跳"的视觉暗示，也是掩体顶面不是空地的理由。

## 已确认的设计决定

- **玩法内核**：保留射击，不改陷阱/非对称
- **美术年代**：现代高饱和卡通（厚描边、平涂、圆润）
- **首张地图**：厨房 Kitchen
- **角色**：四角色 Tom / Jerry / Spike / Butch，**纯外观，无数值差异**
- **投掷物**：全部厨房化（平底锅 / 胡椒瓶 / 面粉袋），外形换、数值不动
- **枪械**：玩具枪（水枪 / 橡皮筋枪 / 玩具步枪）
- **落地范围**：全部做完，分三阶段（界面 → 大厅与道具 → 角色与地图），三阶段均已落地
- **地图换皮**：只换贴图/材质/道具/灯光，**不改碰撞拓扑**（拓扑经 0.5m 栅格洪泛验证）
