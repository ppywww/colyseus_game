# 音效与音频资源规范

> 状态：已确认核心背景音乐设定；具体录音版本、音效清单、音量参数与触发点待补充。

## 1. 核心音乐设定

游戏使用一首贯穿全程的背景音乐：

- **作曲家：** 沃尔夫冈·阿马多伊斯·莫扎特（Wolfgang Amadeus Mozart）
- **作品：** 《C小调第二十四钢琴协奏曲》（Piano Concerto No. 24 in C minor）
- **作品编号：** K.491
- **使用乐章：** 第三乐章
- **使用范围：** 从玩家打开游戏网页开始，贯穿主菜单、创建 / 加入房间、等待阶段以及正式战斗过程。
- **音乐策略：** 全游戏只有这一首背景音乐，不因进入战斗而切换成另一首背景音乐。

该曲是游戏的唯一背景音乐主题。枪声、脚步声、命中反馈、爆炸、 UI 提示等属于独立的游戏音效，不属于背景音乐；它们可在背景音乐播放时按事件触发。

## 2. 播放与场景衔接要求

1. 背景音乐应尽可能从游戏网页启动阶段开始播放，并在主菜单、房间流程和战斗场景之间保持连续。
2. 页面内部切换场景时，不应无故停止后重新播放，也不应每次进入战斗都从头开始。
3. 若因浏览器自动播放策略而无法在用户尚未交互时播放声音，应在首次用户点击 / 按键等有效交互后立即启动，并在后续场景切换中持续播放。
4. 场景切换不应造成明显的音频中断、重复叠播或音量突变。
5. 是否循环播放、淡入淡出方式、是否允许玩家在设置中调节或静音，待后续确认。

## 3. 游戏音效分类

背景音乐以外的音效单独管理，后续按实际资源逐项登记：

- **武器音效：** 射击、换弹、空仓等。
- **角色音效：** 脚步、跳跃、受击、死亡等。
- **战斗反馈：** 命中、击杀、爆炸、投掷物等。
- **界面音效：** 按钮点击、菜单切换、加入房间、倒计时和提示。
- **环境音效：** 地图环境或场景交互音（如实际需要）。

每个音效条目应记录资源文件、触发事件、调用模块、音量分组、是否循环、优先级及停止条件。

## 4. 资源与技术管理

- 音频资源由客户端音频模块管理，不通过 Colyseus 实时状态通道传输。
- 音乐与音效文件通过网页静态资源链路加载，并纳入客户端资源清单和缓存策略。
- 背景音乐可优先加载；对局关键音效应在进入对局前准备完成，避免战斗中首次下载造成延迟。
- 需要避免同一音乐因页面模块重复初始化而叠加播放。
- 音频资源格式、编码、采样率、文件体积和录音来源待根据实际素材确认。

## 5. 版权与素材来源

莫扎特原作属于公有领域，但具体演奏录音、母带和发行版本可能仍受版权或相关邻接权保护。正式发布前需确认所选录音允许游戏内使用、复制、网络分发及必要的商业使用，并记录授权或许可来源。

## 6. 待确认事项

- 采用哪一个具体演奏 / 录音版本，以及音频文件来源。
- 第三乐章是否从头播放、循环播放，还是采用指定片段。
- 首次用户交互前无法自动播放时的启动提示方式。
- 背景音乐默认音量、音效默认音量及设置页的控制方式。
- 是否在特定游戏状态（如暂停、结算、断线）降低音量或停止播放。
- 各类独立游戏音效的具体资源清单和事件映射。
