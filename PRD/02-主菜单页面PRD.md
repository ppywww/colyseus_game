# 02｜主菜单页面 PRD

> 状态：主菜单方向已讨论，视觉细节待最终预览确认
> 适用平台：浏览器桌面端网页游戏
> 文档职责：完整描述主菜单的视觉布局、信息、入口和角色选择交互；全局页面跳转关系见 01。

## 1. 页面目标

主菜单是玩家进入游戏后的主要入口，也是四个原创角色的展示与选择区域。玩家应能在这里确认自己的角色，并直接选择创建房间、加入房间或打开设置。

## 2. 整体视觉方向

- 采用桌面浏览器宽屏布局，不采用手机端或手机横屏 UI。
- 背景为房屋、院子和花园：房屋作为后景，花园作为角色活动区域，前中后景形成空间层次。
- 四个角色位于花园中，以追逐、互动或各自有特点的动作展示；角色手持各自专属装备。
- 整体风格由设计先行判断，要求精致、统一、具有游戏大厅氛围，避免空旷或粗糙。
- UI 不应为了填满画面而增加没有产品用途的入口。

## 3. 玩家信息区

位置：左上角。

- 显示系统分配的随机头像。
- 显示玩家昵称，支持编辑。
- 不显示经验等级、经验条或成长系统信息。
- 玩家名称编辑和头像更换方式由设计给出简洁方案；当前至少保证名称可编辑、头像有默认随机方案。

## 4. 四个角色展示与造型方向

角色参考以用户提供的角色图片为基础，保留四个角色各自的体型特征和辨识度，并优化为适合网页 FPS 游戏的原创卡通造型。

| 暂定称呼 | 外形方向 | 专属装备方向 |
|---|---|---|
| 高瘦蓝猫 | 蓝色、高瘦、灵活 | 水枪 |
| 圆小鼠 | 体型矮小、圆润、古灵精怪 | 弹珠枪 |
| 方块狗 | 方正、厚重、有肌肉感 | 大型盾牌，偏近战 |
| 细长黑猫 | 身形细长、敏捷 | 玩具狙击枪，偏远程 |

造型、动作、服装、材质和装备细节由设计根据参考图与角色定位完成。不得将尚未讨论的装备或角色系统当作已确认需求。

## 5. 角色选择交互

### 5.1 选择方式

- 四个角色都可以直接点击选择。
- 主菜单不增加独立选角页面。
- 初次进入时系统默认选中一个角色。
- 玩家之后可随时点击其他角色切换选择。

### 5.2 奶酪标记动画

- 四个角色脚下都有奶酪造型的选择标记。
- 点击角色后，奶酪标记平滑移动到新角色脚下。
- 当前选中的角色同步放大，其他角色恢复常规比例。
- 标记移动和角色放大属于同一次选择反馈，动画应连贯、快速，不影响连续点击。
- 选择状态必须清晰，不应只依靠颜色变化表达。

### 5.3 选择结果传递

- 点击创建房间时，当前角色作为创建者的默认角色。
- 点击加入房间时，当前角色作为加入者的默认角色。
- 进入 1v1 / 2v2 等待大厅后，玩家仍可在正式开局前按房间规则调整角色。
- 对局开始后锁定本局角色。

## 6. 主菜单主要入口

### 6.1 创建房间

- 右侧主操作区的第一个大按钮。
- 按钮采用醒目的纵向长方形比例，尺寸足够大。
- 点击后进入 03《创建房间页面与三种模式交互》定义的创建流程。

### 6.2 加入房间

- 与创建房间按钮同一操作区域，作为第二个大按钮，上下排列。
- 使用与创建房间一致的视觉体系，明确区分按钮文字和状态。
- 点击后进入 04《加入房间页面与加入流程设计》定义的房间列表。

### 6.3 设置

- 设置入口作为辅助入口保留，不与两个主要房间操作争夺视觉焦点。
- 点击后打开设置页面。
- 设置项目与交互详见 05《游戏内设置页面 PRD》。

## 7. 不应出现的入口与信息

当前主菜单不擅自增加：
- 商城、背包、排行榜、活动中心；
- 经验等级、经验条、成长系统；
- 未讨论的角色解锁、皮肤、付费或任务入口；
- 单独的准星快捷入口（准星属于设置中的一项，不是主菜单独立功能按钮）。

## 8. 页面状态与反馈

- 默认角色选中状态必须明确。
- 鼠标悬停角色时可提供轻量反馈，但不能与选中状态混淆。
- 点击创建 / 加入按钮后应有即时按压或加载反馈，避免重复触发。
- 玩家信息加载失败时，仍应提供可用的默认头像和昵称展示。
- 设置关闭后返回主菜单，并保持之前的角色选择。

## 9. 验收标准

- [ ] 页面为桌面浏览器宽屏布局。
- [ ] 背景呈现房屋、院子和花园的完整空间关系。
- [ ] 四个角色造型符合参考图方向，辨识度明确。
- [ ] 四个角色分别对应水枪、弹珠枪、大型盾牌和玩具狙击枪的装备方向。
- [ ] 左上角显示随机头像和可编辑昵称。
- [ ] 右侧有两个上下排列的大尺寸纵向按钮：创建房间、加入房间。
- [ ] 设置入口清晰可见但不抢主操作焦点。
- [ ] 点击角色后奶酪标记移动，所选角色同步放大。
- [ ] 角色选择结果会带入创建 / 加入流程。
- [ ] 不出现未要求的商城、背包、成长系统等入口。
