# 01｜当前版本问题与主菜单视觉方向

> 状态：待讨论  
> 范围：当前版本体验问题记录、主菜单第一版视觉方向  
> 原则：本文是讨论底稿，不代表所有设计已经定稿；后续以实际预览和用户确认结果为准。

## 1. 项目当前主要问题

根据目前讨论，当前版本存在以下体验问题：

### 1.1 地图与场景

- 当前地图结构和整体观感不符合预期。
- 期望的核心场景方向是一个完整、容易理解的生活化空间：**一栋房子、一个院子，并带有花园等户外区域**。
- 场景需要有鲜明、轻松、有趣的宠物乐园氛围，而不是目前这种缺乏整体感的地图表现。
- 具体房屋结构、院子范围、房间连接方式和场景细节仍待通过效果图讨论。

### 1.2 角色与视觉表现

目前希望优先展示四个原创角色。角色物种可以是猫、鼠、狗，但造型需要形成独立的原创辨识度，不照搬任何现有影视或游戏角色：

| 暂定称呼 | 外形与性格方向 | 专属装备 / 定位 |
|---|---|---|
| 高手猫 | 蓝色、高瘦、气质冷静 | 水枪 |
| 圆小鼠 | 棕色、矮小圆润、古灵精怪 | 弹珠枪 |
| 方块狗 | 身形方正、厚重、肌肉感强 | 大型盾牌，偏近战 |
| 细长黑猫 | 身形细长、敏捷灵活 | 玩具狙击枪，偏远程 |

说明：
- 以上是当前讨论中的角色方向和暂定称呼，后续可以继续调整。
- 角色外形参考用户提供的原创角色参考图，但装备应按上表的设定重新设计。
- 四个角色在主菜单中应有各自鲜明的动作和姿态，形成有趣、活泼的互动场面。
- 角色比例、面部特征、材质、服装和具体动作仍待预览图确认。

### 1.3 道具与战斗反馈

- 当前枪械射击体验不理想，需要后续单独讨论射击反馈、准星、命中表现和操作手感。
- 手榴弹的落点表现和视觉反馈不理想，需要重新设计。
- 道具需要与角色定位和整体卡通世界观协调，避免风格割裂。
- 本节先记录问题，不在本阶段直接规定战斗数值或实现方式。

### 1.4 UI 与房间流程

- 当前 UI 的整体布局和视觉表现不符合预期。
- 游戏不采用复杂的玩家成长系统；玩家进入游戏后可以直接使用或自行修改一个名字，并使用系统提供的随机头像。
- 主菜单不需要经验等级、经验条等成长系统展示。
- 房间相关入口是核心功能，用户明确提出主菜单应突出“创建房间”和“加入房间”。
- FPS 常见设置需要保留，例如准星设置、灵敏度设置等；具体设置项后续再确认。

## 2. 主菜单参考与布局方向

### 2.1 参考图的使用方式

- 用户提供的第一张主菜单截图用于参考信息布局和整体展示方式。
- 用户提供的第二张角色图用于参考四个原创角色的造型方向。
- 参考图只用于理解用户想要的布局和角色概念，不要求照搬其中的具体美术设计。
- 主菜单场景方向为房屋与院子，画面中应能看到房子、院子及花园等环境元素。

### 2.2 初步布局

以手机横屏游戏主菜单为目标，当前布局建议如下：

- **左上角：玩家信息**
  - 显示一个系统随机分配的默认头像。
  - 显示玩家名称。
  - 玩家可以自行编辑名称。
  - 不显示经验等级、经验进度等玩家成长信息。

- **画面中心偏左：角色展示**
  - 展示高手猫、圆小鼠、方块狗、细长黑猫四个原创角色。
  - 四个角色各自持有对应的专属装备。
  - 角色以自然、有趣、富有动势的姿态呈现。
  - 角色整体向画面左侧布置，为右侧主要操作入口留出空间。

- **画面右侧：主要房间操作**
  - 设置两个醒目的大尺寸入口：
    1. 创建房间
    2. 加入房间
  - 两个入口应易于识别和点击，具体按钮样式与交互流程待讨论。

- **设置入口**
  - 保留清晰可见的设置入口。
  - 设置中至少考虑准星设置、灵敏度设置。
  - 其他 FPS 常见设置项待后续梳理。

- **移除的内容**
  - 移除参考图左侧那组纵向功能按钮，不沿用其整套菜单。
  - 不加入排行榜、活动中心、商城、角色成长等尚未确认或不需要的系统入口。

## 3. 主菜单视觉目标

主菜单需要同时满足以下方向：

1. **一眼能看懂**：玩家进入游戏后，能迅速找到创建房间和加入房间。
2. **角色是视觉中心**：四个原创角色及其专属装备是画面重点。
3. **场景有生活感**：通过房子、院子、花园构成完整、温暖且有趣的游戏空间。
4. **卡通但有品质**：角色和场景可以活泼夸张，但造型、材质、光照和 UI 需要统一，不做粗糙或简陋的表现。
5. **手机端优先**：布局以手机横屏的可读性和触控操作为前提，不套用 PC 端竞技游戏大厅的排版。

## 4. 当前阶段的交付方式

当前先做主菜单视觉预览，不进入代码修改阶段。

预览图需要重点验证：

- 房子、院子和花园的场景是否符合预期；
- 四个原创角色的外形是否符合角色设定；
- 四个角色是否拿着正确的专属装备；
- 角色是否位于画面中心偏左；
- 左上角玩家头像和可编辑名称是否简洁；
- 右侧“创建房间”“加入房间”是否足够醒目；
- 设置入口是否清楚；
- 整体是否适合手机横屏。

预览图可以在不改变已明确需求的前提下加入合理的美术创意；但新增功能入口、玩家系统或角色设定不能擅自当作已确认需求。
