### 0.2 本立项书的证据纪律

- 【榜】采用 `[实证]` / `[推断]` / `[未核实]` 三级；【竞】采用【实证·官方】/【实证·媒体】/【实证·社区】/【参考·未核实】/【推断】五级。本文引用时**保留原编号与原等级**，不升格、不合并。
- 凡本文自己下的判断，一律显式写【本文推断】或【本文裁决】，与情报原文结论区分。
- **不引用任何无一手来源的流水 / DAU / eCPM / CAC / 房间服成本单价数字**（【竞】附录 B 第 4、9 条）。
- 冲突口径并列记录、不擅自取舍（包体总量 20M vs 30M、用户画像 45% vs 53% 女性、版号政策多条矛盾说法，见【竞】附录 B 第 6–8 条）。

### 2.3 「空白 ≠ 蓝海」如何纳入判断（必须显式回应）

## 10. 五个争议点 · 正面裁决（不留给定下游）

### 10.1 争议 1｜是否保留「猫鼠战场」玩法内核

> **裁决：保留玩法内核，彻底剥离 IP 符号。这是「靠拢」，不是「坚持」，也不是「整体改赛道」。**【本文裁决】

| 边界 | **保留**（进 Phase 0） | **砍掉 / 换掉**（不进 Phase 0） |
|---|---|---|
| 玩法 | 4v4 阵营对抗 + 回合制胜负骨架与胜负条件（**参数由裴策压**，本立项书只保骨架）；非对称身份 / 目标物驱动 | 「猫 vs 鼠」物种对立设定；奶酪这一具体目标物名称与造型（机制保留、物件换原创） |

### 10.2 争议 2｜原创化改造 + 软著是否作为「不过闸不进 Phase 0」硬条件

2. **命名三项一致且零禁用命中**：产品名 / 买量素材名 / 软著登记名三者一致，且不含「猫和老鼠」「汤姆」「杰瑞」「猫鼠」及近似蹭词；完成商标 / 小游戏名称查重（§4.0）。
3. **软著申请受理回执 + 过程稿归档**：与美术原创化**同步启动**（周期长）。

> **⚠️ 诚实标注（不得对下游包装成法规要求）**：【竞】§3.4④【实证·官方转述】明确 **IAA 软著仅在 3 种情形下需要**（游戏名含英文、含「软件」字样、涉及品牌 / 公众人物合作），故**软著不是本项目 IAA 上架的法定必需**。本立项书把它列进 P-1 硬闸，是基于「原创资产维权核心证据 + Phase 2 内购前置（IAP = 版号 + 软著，缺一不可【实证·官方转述】）+ 名称侵权核对」的**项目级【推断】**。**原创化改造本身是硬阻断实证；软著是项目级硬闸推断，两者性质不同，不得混为一谈。**

**反判后果**：若把原创化降级为「提审前补丁」，【竞】§4.1 已指出平台对「过度借鉴」是责令整改，返工成本高于一次做对【推断】；且脚手架里一旦铺开 IP 命名，全局替换会污染资源名 / 类名 / 素材文案（§9 约束 7）。

### 10.3 争议 3｜4v4 实时联机降级方案：Bot 主导 + 真人渐替，还是直接异步 PvP

> **裁决：主推「Bot 主导（1 真人 + 7 Bot 起）+ 真人渐替」，不直接异步 PvP；异步战绩对战 / 单机 Bot 对抗为备选，给 T1–T4 四条可验证切换阈值。**【本文裁决】

**主推理由**：异步 PvP 会一次性丢掉本项目最核心的「4v4 战术竞技实时感」（§10.1 保留边界内），而 Bot 填充已能解掉冷启动与断线两大风险；【竞】§3.1 汇总判定为「**四个前置缺一即应改异步 PvP / Bot 对抗**」，说明实时是**有条件保留**而非直接放弃；EP-5 闸 2 的落点方向也是「异步 / 好友房 / **AI 填充** / 少量真人，而非 8 人强同步」。`[实证]` 依据：腾讯云 MGOBE 与华为联机对战服务均提供「匹配不足自动填充机器人」【实证·媒体】；微信《网络》文档 5s 后台断线规则【实证·官方】；B8 异步合作生态 `[实证-二手]`。

**主推方案的四项硬条件**（缺一即按阈值降级）：①已备案 wss 域名 + TLS≥1.2；②Bot 撑满 7 位 + 真人渐替；③断线即 Bot 接管 + 前台恢复重连回原房间；④房间服成本模型按峰值房间数先算清【实证·官方 + 推断】。另：**Bot 局走端侧结算、真人局才上房间服**【推断，§5.2 第 5 项】，避免「用真服务器成本跑单机体验」。

**切换到备选的四条可验证阈值（任一触发即切）**：

| 编号 | 触发条件（可验证） | 阈值性质 |
|---|---|---|
| **T1 · 性能** | 8 人同屏低端 iOS 真机 spike 不通过（§7 第 5 项：连续 3 次 <28fps，或出现「看见其他 3D 角色骤降 10–20fps」且降画质兜底无效）→ 切异步 PvP / 单机 Bot 对抗 | 帧率数值来自第三方 checklist【参考·未核实】，**仅内部验收参考、非官方标准** |
| **T2 · 制度 / 成本** | 提审前未取得已备案 wss 域名 + TLS1.2 完整证书链，或房间服成本模型显示冷启动期「1 真人 + 7 Bot」的有状态房间服成本不可接受 → 切异步 | 成本单价**未核实**，本立项书不编造金额，只要求「模型先算清」【推断】 |
| **T3 · 匹配可用性** | 灰度期（前 1000 局或首个 14 天，取先到者）**「20 秒内必开局」达成率 <95%**，或因断线导致**单局完整率 <90%** → 切异步 | 【本文裁决】的内部验收阈值；「20 秒」行业做法为【参考·未核实】 |

> 四条阈值**全部是本立项书设定的项目内部验收阈值（【本文推断】），不是微信官方标准**；数值参考【竞】§5.5 第 3 条与 §3.3⑤【参考·未核实】。切换后仍保住 4v4 **观感**与全部 IAA 点位（【竞】§5.4 备选【推断】），这是把异步留作备选而非主推的关键理由。

### 10.4 争议 4｜是否接受删掉手动瞄准（自动开火 + 强辅助瞄准 + 视角可切）

> **裁决：接受，且明确判定「与保留射击内核不冲突」。**【本文裁决】

**取舍定义（这是本裁决的核心）**：
- **射击内核（保留）** = 玩具武器投射 + 范围 / 溅射 / 状态效果命中反馈 + 击倒播报 + 走位 / 道具选择 / Build 取舍的战术空间。
- **手动精准瞄准（删掉）** = 浏览器 PC 键鼠 FPS 的**输入范式**，不是内核。B4 `[实证]` 已把「PC 键鼠精确瞄准 → 触屏点击」列为**主要改造点**；EP-5 闸 1 把「精准弹道 / 双摇杆瞄准 / 服务端权威命中判定」整体判为 ❌ 不可迁移 `[实证·S3/S4/S5/S14/S10/S11]` + `[推断]` 归因。

**四源同向，可作决策依据**：**TS-1**（榜单长期缺席 `[实证]`）+ **EP-1**（玩具武器天然是范围 / 投掷 / 蓄力语义，建议把命中判定放宽为范围 / 溅射 / 状态效果 `[实证·S13]` 来源 + `[推断]` 迁移）+ **【竞】§3.2② 关键发现**（竖屏射击的共性是**把瞄准删掉**；找不到「竖屏 + 自由移动 + 手动瞄准 + 4v4 实时 PvP」成功产品【推断】，唯一可查证 4V4 实时案例《混乱大枪战》是横屏【实证·媒体】）+ **B3/B4**（竖屏单手硬背景 `[实证-二手]` / `[实证]`）。已验证操作基线：B《迷你枪战精英》双摇杆 + **自动开火 + 自动瞄准** + 陀螺仪可选 + 一/三人称可切【实证·媒体】；A 自瞄 + 人机试炼【实证·媒体】。

**接受的边界（防止删过头，交给裴策的约束）**：
1. 采用【竞】§3.2 **方案 A（或 A+C）**：左虚拟摇杆移动 + 右半屏滑动转向 + 默认自动开火 + 强辅助瞄准 + 陀螺仪可选微调 + 第三人称 / 越肩视角可切。
2. **必须保留三类玩家决策**：憋大招 vs 连发、近身 vs 远距、局内三选一玩具 Build —— 否则退化为自动播放，丢掉 Card 2「规则一句话说完但留有战术空间」`[实证·S13]`。
3. **不得顺带加写实化**：写实弹道 / 血雾 / 拟真后坐力会自毁 §4.2① 的 8+ 合规优势【实证·官方 + 推断】。
4. 前 30 秒零门槛是产品闸条件（§8），自动开火是达成它的手段之一，不是可选项。

**反判后果（明确写死）**：若坚持【竞】§3.2 **方案 D（纯手动双摇杆 FPS）**，该节原文判定应改判为「**不可行**」；则 §7 第 2 项转 🔴，**本立项书结论从「靠拢」降为「不做 / 改赛道」**——因为那等于在 TS-1 所指的空白格子里逆势立项，且首 30 秒零门槛无法满足。

### 10.5 争议 5｜首发范围是否锁定「免版号纯 IAA」

> **裁决：锁定。内购 / 混变不进首发排期，列 Phase 2 并给开启条件。**【本文裁决】

**依据**：【竞】§3.4④【实证·官方转述，基于微信《资质审核-IAP/IAA》】：**IAP = 版号 + 软著，缺一不可；IAA 不要求版号**；但免版号 ≠ 零门槛，须企业主体 + 微信认证 + ICP 备案；【竞】§5.5 第 1 条硬输入明确「首发范围按免版号纯 IAA 定义，内购 / 混变需版号，列 Phase 2，不要写进首发排期」【推断】；【竞】§5.0 / §3.4 判定纯 IAA「可行但天花板明确」——当前瓶颈是**广告位≈0**，不是变现模式不够多【推断】；**B6** `[实证]` 的「内购占 66.8%」是行业结构，**不等于本项目首发可得**【本文推断】。

**首发范围（写死）**：仅自愿激励视频 + 社交裂变奖励；**无内购、无充值、无付费道具、无付费抽取**；≥5 个自愿点位（本立项书给 6 个，§6.2）；**真人局内不售卖战力**；不引用任何收益数字。
**Phase 2 开启条件**：版号实际下发 + 数据闸达标 + LTV>CAC 正向趋势，三条同时满足（§6.4）。版号周期说法互相矛盾【参考·未核实】，**不写入排期依据**。
**政策时效**：以提审当日 mp 后台「资质审核」页与国家新闻出版署最新公告为准（【竞】§5.6 / 附录 B 第 8 条）。

**反判后果**：若首发就排内购 / 混变，等于把「版号审批（周期不可控）+ 12+ 适龄与内容过滤」两条不可控项压进首发关键路径，直接违背「最快合规上架」这一商业闸推进（§8）；且会诱导为「付费变强」而在真人局内售卖战力，踩中 §6.3 红线。
