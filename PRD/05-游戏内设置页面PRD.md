# 05｜游戏内设置页面 PRD

> 状态：功能范围已讨论，控件细节为设计初稿
> 适用平台：浏览器桌面端网页游戏
> 文档职责：定义设置入口、设置分类、控件、预览与保存行为。主菜单设置入口和对局中设置入口共用同一套设置内容。

## 1. 页面目标与原则

设置页面用于调整 FPS 对局体验中直接影响操作和感知的参数。准星和鼠标灵敏度不仅能从主菜单设置，也必须能在游戏过程中打开并调整。

- 设置页面按桌面浏览器宽屏设计。
- 控件信息清楚、精细，调整时能看到当前值和效果。
- 不把准星设置做成主菜单独立入口；它是设置页面内的重要分类。
- 游戏内打开设置时，不应遮挡过多战斗视野。
- 多人对局中打开本地设置不应默认暂停其他玩家的游戏。

## 2. 设置入口

### 2.1 主菜单入口

主菜单保留一个统一的“设置”入口。点击后进入设置页面或设置面板；返回后回到主菜单，并保留当前角色选择。

### 2.2 游戏内入口

正式对局过程中提供可快速访问的设置按钮。点击后打开同一套设置内容，至少包括鼠标灵敏度、准星和声音 / 音效。关闭设置后返回当前对局。

## 3. 鼠标设置

### 3.1 鼠标灵敏度

- 提供连续滑块调节。
- 显示当前数值，支持精细调整。
- 建议提供恢复默认值操作。
- 修改后应能在实际视角控制中感受到变化；具体数值范围需结合现有输入系统确定，不在设计阶段随意写死。

### 3.2 可选项目

- 反转 Y 轴可作为候选项；只有在现有控制系统支持且确认需要时才纳入正式范围。

## 4. 准星设置

准星是 FPS 操作的重要组成部分，设置应比普通音量滑块更细致，并提供实时预览。

### 4.1 建议可调参数

| 参数 | 说明 |
|---|---|
| 样式 | 提供若干预设形状，例如十字、点状等；最终样式由设计确定 |
| 颜色 | 支持选择颜色，并提供高对比度预设 |
| 大小 / 长度 | 调整准星线段或整体尺寸 |
| 粗细 | 调整线段粗细 |
| 中心间距 | 调整准星线段与中心之间的距离 |
| 透明度 | 调整准星透明程度 |
| 中心点 | 如实现合理，提供中心点显示开关 |

以上是建议参数范围，需结合当前准星实现能力确认；不能把建议项误认为已在代码中支持。

### 4.2 实时预览

- 设置面板中提供明显的准星预览区域。
- 调整样式、颜色、大小、粗细、间距或透明度时，预览同步变化。
- 如技术实现允许，预览背景应能切换明暗，帮助判断准星在不同场景中的可见度。
- 应提供恢复默认准星的操作。

### 4.3 对局中调整

- 玩家在对局中打开设置后，可以直接调整准星。
- 关闭面板后，新的准星设置应立即应用于游戏画面，或在明确的应用操作后生效。
- 不应要求玩家退出当前对局才能调整准星。

## 5. 声音与音效设置

- 提供主音量调节。
- 提供音效音量调节。
- 若游戏实际存在独立背景音乐轨道，再提供音乐音量；如果没有音乐轨道，不显示无效控件。
- 滑块旁显示当前数值或百分比，并提供可感知的调整反馈。

## 6. 面板布局建议

- 使用清晰的分类导航：鼠标、准星、声音 / 音效。
- 右侧或主内容区显示当前分类的具体控件。
- 准星分类应给预览区足够空间，不要将所有参数挤成密集小控件。
- 底部或固定区域提供恢复默认、应用（如需要）和关闭操作。
- 视觉风格沿用主菜单与房间页面的卡通游戏 UI 体系。

## 7. 保存与生效规则

- 设置修改应有明确的生效反馈。
- 优先支持调整后即时预览；是否需要单独点击应用，由技术实现与体验验证决定。
- 关闭设置后保留本次修改。
- 恢复默认应有明确反馈，避免误触后无法恢复。
- 设置应尽可能跨页面保持一致：主菜单修改后进入对局仍沿用；对局中修改后返回主菜单也应保留。
- 设置存储方式与跨设备同步能力需结合项目现有账号 / 本地存储能力确定。

## 8. 验收标准

- [ ] 主菜单只有一个统一设置入口。
- [ ] 对局中存在可访问的设置入口。
- [ ] 主菜单和游戏内打开的是同一套设置内容。
- [ ] 鼠标灵敏度可调并显示当前值。
- [ ] 准星包含细致的自定义项目，并提供实时预览。
- [ ] 玩家无需退出对局即可调整准星。
- [ ] 提供主音量和音效音量调节。
- [ ] 设置关闭后修改仍然保留。
- [ ] 恢复默认操作清晰可用。
- [ ] 不展示当前游戏并不存在的设置项目。

## 9. 待技术核对事项

1. 当前准星渲染支持哪些参数，以及哪些参数需要补充开发。
2. 鼠标灵敏度的实际取值范围和默认值。
3. 当前音频系统是否区分主音量、音效和音乐。
4. 设置保存到本地还是账号；是否需要跨浏览器 / 设备同步。
5. 游戏内设置打开时鼠标锁定、视角输入和游戏暂停的具体处理方式。
