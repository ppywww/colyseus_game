# 猫鼠战场 · 玩法简介（v0.2）

> 配套 `产品视觉效果手册.html` 使用。这是玩法层的说明，视觉规范以手册为准。

## 一句话

四个卡通动物，在一间放大了三倍的厨房里，用枪和厨房道具打 **4v4 回合制对抗**。尺度反差是全部乐趣的来源。

## 定位

| 项 | 内容 |
| --- | --- |
| 类型 | 第一人称战术竞技（团队对抗） |
| 人数 | 4v4，单房间最多 8 人 |
| 时长 | 单回合 90 秒，先到 12 击杀或打满 5 回合 |
| 平台 | 浏览器（Three.js + Colyseus），桌面键鼠 |
| 底层 | 服务端权威：命中、伤害、投掷弹道全部由服务端裁定 |

## 核心循环

1. **出生推进**：鼠方从餐桌下的鼠洞出生，猫方从冰箱后出生，各自选一条通道。
2. **换血与抢点**：用地形与厨房物件当掩体换血，抢占奶酪点补充弹药。
3. **投掷物清点**：平底锅逼位、胡椒瓶破点、面粉袋切视线，抛物线所见即所得。
4. **回合结算**：MVP 与伤害榜，结算页承担表演欲。

## 地图 · KITCHEN

12m × 8m（真实厨房 4m × 3m 放大 3 倍）。三条通道：

- **① 台面高线**：沿料理台前沿，能俯瞰中央地砖，但暴露在三条视线交叉处。
- **② 中央地砖**：最短路径，掩体最少，适合烟雾掩护下快速转点。
- **③ 桌下通道**：头顶是桌布，几乎不被高线打中；狭窄，易被一颗手雷封死。

掩体全部是厨房物件：奶酪（可绕后、可补给）、罐头（圆柱，可擦边射击）、面包（蹲下完全遮蔽）、盘子堆（垂直掩体，打碎后消失）。

## 已确认的设计决定

- **玩法内核**：保留射击，不改陷阱/非对称
- **美术年代**：现代高饱和卡通（厚描边、平涂、圆润）
- **首张地图**：厨房 Kitchen
- **角色**：四角色 Tom / Jerry / Spike / Butch
- **投掷物**：全部厨房化（平底锅 / 胡椒瓶 / 面粉袋），外形换、数值不动
- **枪械**：玩具枪（水枪 / 橡皮筋枪 / 玩具步枪）
- **落地范围**：全部做完，分三阶段（界面 → 大厅与道具 → 角色与地图）
